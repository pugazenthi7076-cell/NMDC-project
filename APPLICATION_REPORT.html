1. 📌 Project Overview

Problem

Conveyor belt failures in mining cause costly downtime, safety hazards, and production losses. Manual inspections are slow and unreliable.

Solution

AI-powered real-time monitoring system that combines 7 sensor types, machine learning predictions, computer vision, and automated alerts to predict belt failures before they happen.

Target Users

Maintenance engineers, operations managers, safety officers at NMDC mining facilities.

Key Outcome

91.5% failure prediction accuracy, 7 sensor types monitored, 7 defect classes detected, real-time alerts via SMS/Email/Webhook.

4. 🤖 AI / Analytics & Application Layer

4.1 OpenCV — Image Processing

  • Module: opencv_processor.py — BeltImageProcessor class
  • Capabilities: Crack detection (morphological ops), tear detection (contour analysis), surface abrasion (texture variance), edge damage (zone analysis), misalignment (Hough line detection)
  • API: POST /analyze/image, POST /analyze/frame

4.2 YOLOv8 — Real-Time Object Detection

  • Module: yolo_detector.py — BeltYOLODetector class
  • 7 Defect Classes: belt_tear, surface_crack, splice_failure, edge_damage, abrasion, misalignment, foreign_object
  • API: POST /detect/yolo, GET /detect/yolo/simulate

4.3 XGBoost + Random Forest

  • Module: train_models.py — 5 trained models
  • Models: Failure Predictor (XGBoost, 91.5%), Health Scorer (XGBoost, MAE 7.68%), Damage Classifier (RF, 7 classes), Remaining Life (RF, MAE 2.4 days), Severity Classifier (RF, 3 levels)
  • Training: 2,000 synthetic samples based on real conveyor belt patterns
  • API: POST /predict/full, /predict/failure, /predict/health

4.4 1D-CNN / LSTM — Time-Series Anomaly Detection

  • Module: deep_learning.py — Vibration, Temperature, Motor Current, Acoustic analyzers
  • Features: FFT frequency analysis, kurtosis, crest factor, spectral centroid, harmonic distortion, trend detection, statistical process control
  • API: POST /analyze/vibration, /analyze/temperature, /analyze/motor-current, /analyze/acoustic

4.5 Sensor Fusion

  • Module: sensor_fusion.py — SensorFusionEngine class
  • Methods: Weighted voting (7 sensors × reliability scores), Bayesian fusion (prior/posterior probability), cross-sensor correlation analysis, root cause inference
  • API: POST /fusion/analyze, /fusion/correlate

4.6 MQTT — Real-Time Sensor Communication

  • Module: mqtt_client.py — MQTTManager class
  • Topics: nmdc/belt/{belt_id}/{sensor_type} for 7 sensor types
  • Features: Auto-subscribe, history (100 readings/sensor/belt), alert publishing, simulated mode for testing
  • API: GET /mqtt/status, /mqtt/sensors, POST /mqtt/publish, /mqtt/simulate/{belt_id}

4.7 MinIO — Object Storage

  • Module: minio_storage.py — MinIOStorage class
  • 4 Buckets: nmdc-belt-images, nmdc-detections, nmdc-reports, nmdc-logs
  • API: POST /minio/upload/image, /minio/upload/detection, /minio/upload/report, GET /minio/list/{bucket}
